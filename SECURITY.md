# Security Policy

## Supported Version

Security fixes are applied to the latest release and the `main` branch.

## Reporting a Vulnerability

Do not publish sensitive details, private filenames, credentials, or personal
documents in a public issue. Use GitHub's **Report a vulnerability** option when
it is available. Otherwise, open a minimal issue requesting a private contact
channel without including exploit details or private data.

Include the affected version, impact, reproduction conditions using disposable
files, and any suggested mitigation. Reports will be acknowledged through the
available GitHub channel before a public fix is discussed.
