# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Reproducible temporary-directory demo executed by CI.
- Structured bug, feature, and pull request templates.
- Security reporting guidance and a public v1.1.0 roadmap issue.

## [1.0.0] - 2026-10-07

### Added

- Safe dry-run mode as the default behavior.
- Explicit `--apply` option for moving files.
- Organization into Images, Documents, Videos, Audio, Archives, Code, and
  Others categories.
- Case-insensitive extension matching.
- Collision-safe destination names that preserve existing files.
- Hidden-file exclusion by default and the `--include-hidden` option.
- Automated unit tests for core behavior and safety guarantees.
- GitHub Actions testing on supported Python versions.
- Contributor documentation and release history.
